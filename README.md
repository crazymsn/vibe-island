# Vibe Island

### DeepCloud 的统一 AI Agent 调度台

</div>

Vibe Island 是一款面向 macOS 的 AI Agent 统一管理工具，通过集成 Claude Code、Codex、Gemini CLI、OpenCode 等 30 余种 AI 编程 Agent，将多个 Agent 的运行状态、任务进度、执行日志、权限审批、问题交互及模型使用额度集中展示在 MacBook 灵动岛区域。支持一键跳转对应终端会话、实时接收任务通知、审批 Agent 操作、SSH 远程管理等功能，旨在降低多 Agent 并行开发时的监控与交互成本，实现轻量化、非侵入式的 AI Agent 统一管理。
